# Demo Demonios (prototipo para PS Vita)

Combate por turnos minimo: Atacar, Fuego (el demonio es debil: dano x2 y turno extra) y Curar.
Controles: arriba/abajo = mover, X = elegir, START = reiniciar, SELECT = salir.

## Como obtener el .vpk sin programar (GitHub)
1. Crea una cuenta en github.com y un repositorio nuevo.
2. Sube TODO el contenido de esta carpeta (incluida la carpeta oculta .github).
3. Ve a la pestana "Actions", abre "Compilar VPK" y espera a que termine.
4. Descarga el artefacto "demo-demonios-vpk" (un zip con el .vpk dentro).
5. Pasa el .vpk a tu Vita (con VitaShell) e instalalo. Requiere Vita con homebrew.
